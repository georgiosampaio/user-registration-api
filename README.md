
# User Registration API

An early Spring Boot REST API project documenting my progression in Java backend development.

## About

This project focuses on user management operations and represents an earlier stage of my backend development journey.

## Configuration

The following environment variables are required to connect to the database:

- `DB_URL`
- `DB_USERNAME`
- `DB_PASSWORD`

## Running the Application

On Windows, run the following command from the project root:

`.\mvnw.cmd spring-boot:run`

## Project Status

This project is part of my backend development portfolio and reflects my practical experience with Java and Spring Boot.
